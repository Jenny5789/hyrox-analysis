# 용어 정리

노트북에서 사용한 분석·코드 용어의 정의. 일반 용어와 프로젝트 정의 용어를 구분하여 정리함.

## 일반 용어

### 데이터

| 용어 | 뜻 | 노트북 |
|---|---|---|
| 정형 데이터 (structured data) | 행·열과 열 이름(스키마)이 정해진 표 형태의 데이터 | 01 |
| 데이터프레임 (DataFrame) | pandas에서 표 데이터를 다루는 구조, 코드에서는 `df` | 01 |
| 결측 (missing value) | 값이 비어 있는 상태 | 01 |
| 이상값 (outlier) | 다른 값과 크게 떨어진 값, 오류일 수도 실제 기록일 수도 있음 | 01, 02 |
| 특징 (feature) | 모델의 입력으로 사용하는 열 | 03 |

### 통계

| 용어 | 뜻 | 노트북 |
|---|---|---|
| 중앙값 (median) | 값을 크기순으로 놓았을 때 가운데 값, 이상값의 영향이 작음 | 01 |
| 사분위수 (quartile) | 값을 크기순으로 4등분하는 경계값 (25%, 50%, 75%) | 01 |
| 표준편차 (standard deviation) | 값이 평균에서 떨어진 정도의 평균적 크기 | 01 |
| 산포 (dispersion) | 값이 중심에서 흩어진 정도, 표준편차·사분위수 등으로 표현 | 01 |
| 왜도 (skewness) | 분포가 한쪽으로 치우친 정도, 양수이면 오른쪽 꼬리가 긺 | 01 |
| 히스토그램 (histogram) | 값의 범위를 구간으로 나누고 구간별 기록 수를 막대로 나타낸 그래프 | 01 |
| 밀도 (`density=True`) | 히스토그램에서 막대 면적의 합을 1로 맞춘 척도, 기록 수가 다른 집단의 분포 형태 비교에 사용 | 01 |
| 산점도 (scatter plot) | 두 값을 가로·세로 축의 점으로 나타낸 그래프 | 03 |
| 상관계수 (correlation coefficient) | 두 값이 함께 변하는 방향과 정도를 나타내는 지표, -1~1 범위이며 인과를 의미하지 않음 | 03 |
| 표본추출 (sampling) | 전체 기록에서 일부를 무작위로 뽑는 것 | 03 |
| 표준화 (standardization) | 값을 평균 0, 표준편차 1로 변환하여 단위와 크기를 통일 (`StandardScaler`) | 03 |
| 재현성 (reproducibility) | 같은 코드와 데이터로 다시 실행했을 때 같은 결과가 나오는 성질 | 03 |

| 상관계수 값 | 의미 |
|---|---|
| 1에 가까움 | 한 값이 클수록 다른 값도 큰 경향 |
| -1에 가까움 | 한 값이 클수록 다른 값은 작은 경향 |
| 0 근처 | 선형 관계가 거의 없음 |

### 군집

| 용어 | 뜻 | 노트북 |
|---|---|---|
| 비지도 학습 (unsupervised learning) | 정답 라벨 없이 데이터의 구조를 찾는 학습 방식 | 03 |
| 군집화 (clustering) | 값이 유사한 기록끼리 묶는 비지도 학습 | 03 |
| 군집 수 (k) | 생성할 군집의 개수, K-Means에서 사전에 지정 | 03 |
| 군집 중심 (centroid) | 군집에 속한 기록의 평균 위치 | 03 |
| K-Means | 군집 중심 k개를 정하고, 기록을 가장 가까운 중심에 배정한 뒤 중심을 갱신하는 과정을 반복하는 군집화 방법 | 03 |
| 관성 (inertia) | 각 기록과 가장 가까운 군집 중심 사이 거리의 제곱합 (군집 내 제곱합), 작을수록 군집 내부가 밀집 | 03 |
| 엘보 방법 (elbow method) | k를 늘리며 관성의 감소 폭이 줄어드는 지점을 k 후보로 선택하는 방법 | 03 |
| 실루엣 점수 (silhouette score) | 군집 간 분리 정도를 나타내는 지표, -1~1 범위이며 클수록 군집이 뚜렷함 | 03 |
| 군집 프로파일링 (cluster profiling) | 군집별 요약 통계를 계산하여 군집의 특성을 비교하는 작업 | 03 |

실루엣 점수 계산
- 기록별로 a(같은 군집 기록과의 평균 거리), b(가장 가까운 다른 군집 기록과의 평균 거리) 계산
- 점수 = (b − a) ÷ max(a, b)
- 전체 기록의 평균을 k별 점수로 사용
- 기록 쌍마다 거리를 계산하므로 계산량이 커서 표본으로 계산

| 실루엣 점수 | 의미 |
|---|---|
| 1에 가까움 | 군집 내부는 밀집하고 다른 군집과는 분리됨 |
| 0 근처 | 군집 경계에 위치하여 구분이 모호함 |
| 음수 | 다른 군집에 더 가까워 잘못 배정되었을 가능성 |

### 회귀

| 용어 | 뜻 | 노트북 |
|---|---|---|
| 지도 학습 (supervised learning) | 정답(예측 대상)이 있는 데이터로 입력과 정답의 관계를 학습하는 방식, 정답 없이 구조를 찾는 비지도 학습과 대비 | 04 |
| 회귀 (regression) | 지도 학습 중 숫자 값(예: 시간)을 예측하는 작업 | 04 |
| 입력 (X)·예측 대상 (y) | 입력은 예측에 쓰는 열(특징과 같은 뜻), 예측 대상은 모델이 맞히려는 값 | 04 |
| 학습·시험 데이터 (train·test) | 학습 데이터는 모델이 관계를 찾는 데 사용, 시험 데이터는 학습에 쓰지 않고 최종 성능 확인에만 사용 | 04 |
| 누수 (leakage) | 예측 대상의 정보가 입력에 섞여 점수가 실제보다 좋게 나오는 문제 | 04 |
| 검증·교차검증 (validation·cross-validation) | 학습 데이터 안에서 학습용과 검증용을 나눠 모델을 비교하는 것, 나누는 방식을 바꿔 반복하면 교차검증, 시험 데이터를 모델 선택에 쓰지 않기 위해 사용 | 04 |
| 기준선 (baseline) | 모델과 비교하기 위한 단순한 예측 방법, 모델 점수가 기준선보다 좋아야 모델을 쓸 이유가 생김 | 04 |
| 오차 (error) | 예측값 − 실제값, 양수이면 실제보다 크게, 음수이면 작게 예측한 것 | 04 |
| MAE (평균 절대 오차) | 오차 절대값의 평균, 단위는 예측 대상과 같고(분) 작을수록 정확 | 04 |
| R² (결정계수) | 1 − (모델 오차 제곱합 ÷ 실제값 평균으로 예측한 오차 제곱합), 1이 최대이며 보편적인 좋고 나쁨의 기준은 없음 | 04 |
| 선형 회귀 (linear regression) | 입력에 계수를 곱해 더한 값으로 예측하는 모델, 직선 관계를 가정하며 계수는 오차 제곱합이 최소가 되도록 결정 (`LinearRegression`) | 04 |
| 다중공선성 (multicollinearity) | 입력 열끼리 상관이 높은 상태, 선형 회귀의 계수가 불안정해질 수 있음 (scikit-learn 공식 문서) | 04 |
| 릿지 회귀 (ridge regression) | 선형 회귀에 계수가 커지는 것을 억제하는 벌점을 더한 모델 (`Ridge`) | 04 |
| 결정 트리 (decision tree) | 입력 값에 대한 조건(예: 런 4구간이 일정 값 미만인지)으로 기록을 반복해서 나누고, 나뉜 끝의 예측 대상 평균을 예측값으로 쓰는 모델 | 04 |
| 앙상블 (ensemble) | 여러 모델의 예측을 합쳐 하나의 예측으로 쓰는 방법 | 04 |
| 랜덤 포레스트 (random forest) | 무작위성을 준 결정 트리를 여러 개 만들고 예측을 평균하는 앙상블 모델, 직선이 아닌 관계도 반영 가능 (`RandomForestRegressor`) | 04 |

| R² 값 | 의미 |
|---|---|
| 1 | 실제값과 완전히 일치 |
| 0 근처 | 실제값 평균으로 예측한 것과 비슷한 수준 |
| 음수 | 실제값 평균으로 예측한 것보다 나쁨 |

### 코드

| 용어 | 뜻 | 노트북 |
|---|---|---|
| `shape` | 데이터프레임의 (행 수, 열 수) | 01 |
| `iloc` | 위치 번호(0부터)로 행을 선택하는 방법, `.iloc[0]`은 첫 행 | 01 |
| 상대 경로 | 현재 파일 위치를 기준으로 한 경로, `../`는 상위 폴더 | 01 |
| `index=False` | CSV 저장 시 행 번호 열을 제외하는 옵션 | 01 |
| `bins` | 히스토그램에서 값의 범위를 나누는 구간(막대) 수 | 01 |
| `nunique()` | 서로 다른 값의 개수 | 01 |
| `shift()` | 값을 한 칸 아래로 이동하여 바로 위 행과 비교할 수 있게 하는 함수 | 01 |
| `is_monotonic_increasing` | 값이 끝까지 오름차순(같은 값 포함)인지 여부 | 01 |
| `describe()` | 개수·평균·표준편차·최솟값·사분위수·최댓값을 한 번에 계산 | 01, 02, 03 |
| `groupby()` | 같은 값을 가진 행을 집단으로 묶어 집단별로 계산 | 01, 03 |
| `agg()` | 집단별로 열마다 계산 방식(`size`, `median` 등)을 지정 | 03 |
| `duplicated(keep=False)` | 중복 그룹에 속한 기록 전체를 표시 | 02 |
| `duplicated()` | 첫 기록을 제외한 중복 기록만 표시 | 02 |
| `drop_duplicates()` | 중복 기록 중 첫 기록만 유지 | 02 |
| `n_init` | 시작 중심을 달리하여 K-Means를 실행하는 횟수, 관성이 가장 작은 결과를 사용 (기본값 `'auto'`는 `k-means++`에서 1회) | 03 |
| `random_state` | 무작위 과정(시작 중심, 표본 추출)을 고정하여 재현성을 확보하는 설정 | 03 |
| `labels_` | K-Means가 각 기록에 부여한 군집 번호 | 03 |
| `inertia_` | K-Means 결과의 관성 값 | 03 |
| `alpha` | 릿지 회귀에서 계수를 억제하는 벌점의 세기, 클수록 억제가 강함 (기본값 1.0) | 04 |
| `n_estimators` | 랜덤 포레스트에서 만드는 결정 트리 개수 (기본값 100) | 04 |
| `min_samples_leaf` | 결정 트리의 분할 끝에 남아야 하는 최소 기록 수, 1이면 제한 없음 (기본값 1) | 04 |
| `corrwith()` | 데이터프레임의 각 열과 다른 값 사이의 상관계수를 한 번에 계산 | 04 |
| `qcut()` | 기록 수가 같아지도록 값을 구간으로 나눔, 값의 범위를 나누는 `bins`와 다름 | 04 |
| `fit()`·`predict()` | `fit()`은 학습 데이터로 모델을 학습, `predict()`는 학습된 모델로 입력에 대한 예측값을 계산 | 04 |

## 프로젝트 정의 용어

일반 용어로 대응되는 표현이 없어 이 프로젝트에서 직접 정의한 용어.

| 용어 | 정의 | 노트북 |
|---|---|---|
| 중복 기록 | 모든 열(구간 기록 포함)이 같은 기록, 선수 식별 열이 없어 동일 기록의 중복 등재로 추정 | 02 |
| 런 비율 | `run_time` ÷ 해당 기록의 런 구간(8개) 중앙값, 구간 시간이 고르면 약 8 | 02 |
| 배율 | 런 구간 최댓값 ÷ 해당 기록의 런 구간 중앙값 | 02 |
| 구간 이상 | 배율 5배 이상인 기록, 02에서 제외 | 02 |
| 이탈 | 정한 범위에서 벗어난 기록 전체 (미만 + 초과) | 02 |
| 극단 기록 | 런 비율이 6.5배 미만 또는 12배 초과인 기록, 탐색용이며 제외 기준과 별개 | 02 |
| 비중 | 유형별 시간 ÷ 총 기록 (런·스테이션·록스존), 세 비중의 합은 1 | 03 |
| 런 비중 | `run_time_sec` ÷ `total_sec`, 02의 런 비율과 다른 값 | 03 |
| 후반 런 하락 | 런 5~8구간 평균 ÷ 런 1~4구간 평균, 1보다 클수록 후반 런이 느림 | 03 |
| 시즌 | `event_name` 앞 두 글자(S4·S5·S6)로 구분한 대회 묶음, 달력 연도와 같지 않음 | 04 |
| 후반 소요 시간 | 런 5~8구간·스테이션 5~8구간·록스존 5~7구간 11개 열의 합(분), `roxzone_8`은 전 기록이 0초라 제외 | 04 |
| 전반 합 × 비율 | 기준선의 예측값, 전반 12열 합에 비율(학습 데이터의 후반 ÷ 전반 중앙값)을 곱하고 60으로 나눠 분 단위로 변환 | 04 |
