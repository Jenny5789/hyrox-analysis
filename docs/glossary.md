# 용어 정리

노트북에서 사용한 분석·코드 용어의 뜻. 노트북을 진행하며 추가함.

## 데이터

| 용어 | 뜻 | 노트북 |
|---|---|---|
| 정형 데이터 | 행·열과 열 이름(스키마)이 정해진 표 형태의 데이터 | 01 |
| 데이터프레임 (DataFrame) | pandas에서 표 데이터를 다루는 구조, 코드에서는 `df` | 01 |
| 결측 | 값이 비어 있는 상태 | 01 |
| 이상값 | 다른 값과 크게 떨어진 값, 오류일 수도 실제 기록일 수도 있음 | 01, 02 |

## 통계

| 용어 | 뜻 | 노트북 |
|---|---|---|
| 중앙값 | 값을 크기순으로 놓았을 때 가운데 값, 이상값의 영향이 작음 | 01 |
| 왜도 (skewness) | 분포가 한쪽으로 치우친 정도, 양수면 오른쪽 꼬리가 긺 | 01 |
## 통계

| 용어 | 뜻 | 노트북 |
|---|---|---|
| 히스토그램 | 값의 범위를 구간으로 나누어 구간별 기록 수를 막대로 보여 주는 그래프 | 01 |

## 코드

| 용어 | 뜻 | 노트북 |
|---|---|---|
| `shape` | 데이터프레임의 (행 수, 열 수) | 01 |
| `iloc` | 위치 번호(0부터)로 행을 고르는 방법, `.iloc[0]`은 첫 행 | 01 |
| 상대 경로 | 현재 파일 위치를 기준으로 한 경로, `../`는 상위 폴더 | 01 |
| `index=False` | CSV 저장 시 행 번호 열을 제외하는 옵션 | 01 |
## 코드

| 용어 | 뜻 | 노트북 |
|---|---|---|
| `bins` | 히스토그램에서 값의 범위를 나누는 구간(막대) 수, 클수록 세밀하고 작을수록 뭉툭함 | 01 |
| `nunique()` | 서로 다른 값의 개수 | 01 |
| `shift()` | 값을 한 칸 아래로 밀어서 바로 위 행과 비교할 수 있게 하는 함수 | 01 |
| `is_monotonic_increasing` | 값이 끝까지 오름차순(같은 값 포함)인지 여부 | 01 |

## 통계

| 산포 | 값이 중심에서 흩어진 정도, 표준편차·사분위수 등으로 나타냄 | 01 |
| 표준편차 | 평균에서 값이 평균적으로 얼마나 떨어져 있는지 | 01 |
| 사분위수 | 값을 크기순으로 4등분하는 경계값 (25%, 50%, 75%) | 01 |
| 밀도 (`density=True`) | 막대 면적의 합을 1로 맞춘 척도, 기록 수가 다른 집단의 분포 형태를 비교할 때 사용 | 01 |
