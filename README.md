## HYROX 경기 구성

- 1km 달리기(런)와 운동 스테이션을 번갈아 8회 반복하는 피트니스 대회
  - 런 1km → 운동 스테이션 1 → 런 1km → 운동 스테이션 2 → … → 운동 스테이션 8 → 결승
- 운동 스테이션 순서
  - 스키에르그 → 슬레드 푸시 → 슬레드 풀 → 버피 브로드 점프 → 로잉 → 파머스 캐리 → 샌드백 런지 → 월볼
- 록스존(Roxzone): 런과 운동 스테이션 사이를 이동하는 전환 구간
- 이 분석에서 **1구간 = 런 1회 + 운동 스테이션 1개 + 록스존 1회**
  - 8구간 × 3종류 = 기록 열 24개
  - 8구간 록스존은 마지막 스테이션 뒤가 바로 결승선이라 모든 기록이 0초 → 실제 분석 대상은 23개
- 부문
  - 오픈 싱글: 일반 개인 부문
  - 프로 싱글: 운동 스테이션 무게가 더 무거운 개인 부문

## 분석 기준 상세

- **평가 설계**
  - 원본이 대회 단위로 묶여 있어 앞에서부터 자르지 않고 시즌으로 분할 (학습: 시즌 4·5, 시험: 시즌 6)
  - 모델 선택은 학습 데이터 안의 시즌 교차 검증(S4→S5, S5→S4)으로 수행
  - 시즌 6은 선택한 모델과 기준선 평가에 한 번만 사용
- **데이터 누수 점검**
  - 입력은 1~4구간, 예측 대상은 5~8구간으로 나누어 겹침 없음 확인
  - 완주 시간 = 런 + 운동 스테이션 + 록스존 합이 모든 기록에서 일치 (불일치 0건)
- **기준선 비교**
  - 모든 모델 점수를 단순 계산 결과(기준선)와 함께 제시
- **결과 안정성 확인**
  - 실루엣 계산 표본 크기(5천·1만·2만 건), K-Means 초기화 횟수(`n_init` 1·10·30)를 바꿔 군집 결과 재확인
- **분석 기록**
  - 전처리 제외 기준마다 영향 건수 기록
  - scikit-learn 기본값 사용, 근거 없이 정한 값(`random_state=42`, 등급 경계, 이상 기록 5배 기준 등)은 노트북에 명시
  - 결과에는 확인한 값만, 해석과 한계는 별도 기록

## 한계

- 후반 감속의 원인(피로, 페이스 배분, 직전 운동 스테이션 영향 등)은 이 데이터로 확인 불가
- 회귀: 랜덤 포레스트와 선형 모델의 차이(0.06~0.13분)가 작고 검증이 2회뿐이라 의미 있는 차이인지 구분 불가
- 분류: 등급(완주 시간)에 입력(1~4구간 기록)이 포함되어 점수가 높게 나올 수 있음
- 분류: 오픈·프로 싱글의 운동 스테이션 무게 차이가 데이터에 없어, 같은 시간이라도 부문 간 의미가 다를 수 있음
- 군집: 실루엣 0.353으로 경계가 뚜렷하지 않아 유형이 아닌 경향 수준의 구분
- 전처리: 이상 기록 38건을 제외한 결과와 유지한 결과는 비교하지 않음
- 모델 설정: scikit-learn 기본값만 사용
- 선수 식별 열이 없어 학습·시험 데이터에 같은 선수가 있는지 확인 불가
- 시즌 4~6 데이터라 최신 경향은 반영하지 못함

## 회고

- **정형 데이터 ML 분석 전 과정을 처음부터 끝까지 직접 수행**
  - EDA → 전처리 → 군집 → 회귀 → 분류를 하나의 데이터셋으로 진행
- **과정에서 체감한 점**
  - 데이터를 어떻게 나누느냐(시즌 단위 분할)에 따라 평가 결과가 달라짐
  - 모델 점수는 단순 기준선과 비교해야 의미가 생김
