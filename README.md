### 주요 발견

- 런 구간 중앙값이 1구간 4:31에서 8구간 6:14로 약 38% 증가
- 세 군집 모두 후반(5~8구간) 런이 전반(1~4구간)보다 느림
  - 후반 감속 정도: 군집별 약 9% / 12% / 27%
  - 감속이 가장 큰 군집의 완주 시간 중앙값 103.2분으로 가장 느림
- 1~4구간 기록만으로 5~8구간 소요 시간 예측 시 MAE 약 3분
  - 단순 비율 계산(MAE 3.36분) 대비 개선은 0.37분에 그침
- 등급 분류 오답 2,843건 중 2,836건이 한 등급 차이로, 크게 벗어난 예측은 거의 없음

## 프로젝트 동기

- HYROX 대회 참가 경험에서 출발
- 참가 당시 "후반에 느려지는 사람이 많아 체력 배분이 중요하다"는 이야기를 자주 접함
- 구간별 기록이 모두 남아 있는 공개 데이터를 발견
- **핵심 질문: 선수들은 후반에 실제로 얼마나 느려지는가**
- 이 질문을 출발점으로 분석 범위를 확장
  - EDA: 완주 시간과 구간별 기록 분포 확인
  - 군집: 후반 감속 정도로 선수 경향 구분
  - 회귀·분류: 전반 기록으로 후반 기록과 완주 시간 등급 예측

## HYROX 경기 구성

- 1km 달리기(런)와 운동 스테이션을 번갈아 8회 반복하는 피트니스 대회
  - 런 1km → 운동 스테이션 1 → 런 1km → 운동 스테이션 2 → … → 운동 스테이션 8 → 결승
- 운동 스테이션 순서
  - 스키에르그 → 슬레드 푸시 → 슬레드 풀 → 버피 브로드 점프 → 로잉 → 파머스 캐리 → 샌드백 런지 → 월볼
- 록스존(Roxzone): 런과 운동 스테이션 사이를 이동하는 전환 구간
- 이 분석에서 **1구간 = 런 1회 + 운동 스테이션 1개 + 록스존 1회**
  - 8구간 × 3종류 = 기록 열 24개
  - 8구간 록스존은 마지막 스테이션 뒤가 바로 결승선이라 모든 기록이 0초 → 실제 분석 대상은 23개
- 부문
  - 오픈 싱글: 일반 개인 부문
  - 프로 싱글: 운동 스테이션 무게가 더 무거운 개인 부문

## 데이터

- 출처: Kaggle [Hyrox Race Results](https://www.kaggle.com/datasets/jgug05/hyrox-results) (jgug05), CC BY 4.0
- 원본: 92,374행 × 34열, 시즌 4~6 (S4~S6)
- 분석 범위: 오픈 싱글·프로 싱글 부문 61,832건
  - 2인(더블)·4인 릴레이 등 경기 형식이 다른 부문 제외
- 분석 데이터: 전처리 후 59,886건 (오픈 싱글 49,041건, 프로 싱글 10,845건)
- 행의 의미: 1회 완주 기록
  - 선수 식별 열이 없어 같은 선수의 기록인지 구분 불가

## 분석에서 지킨 기준

- **시즌 단위 분할**
  - 원본이 대회 단위로 묶여 있어 앞에서부터 자르지 않고 시즌으로 분할
  - 학습: 시즌 4·5, 시험: 시즌 6
- **시험 데이터 분리**
  - 모델 선택은 학습 데이터 안의 시즌 교차 검증(S4→S5, S5→S4)으로 수행
  - 시즌 6은 선택한 모델과 기준선 평가에 한 번만 사용
- **데이터 누수 방지**
  - 입력은 1~4구간, 예측 대상은 5~8구간으로 나누어 겹침 없음 확인
  - 완주 시간 = 런 + 운동 스테이션 + 록스존 합이 모든 기록에서 일치 (불일치 0건)
- **기준선 비교**: 모든 모델 점수를 단순 계산 결과(기준선)와 함께 제시
- **설정값 근거 표기**
  - scikit-learn 기본값 사용
  - 근거 없이 정한 값(`random_state=42`, 등급 경계 등)은 노트북에 명시
- **관찰과 해석 분리**: 결과에는 확인한 값만, 해석과 한계는 별도 기록

## 배운 점

- **정형 데이터 ML 분석 전 과정을 처음부터 끝까지 직접 수행**
  - EDA → 전처리 → 군집 → 회귀 → 분류를 하나의 데이터셋으로 진행
- **단계별로 익힌 것**
  - EDA: 시간 문자열 변환, 분포·중앙값으로 데이터 특성 파악
  - 전처리: 중복·0초·이상 기록의 제외 기준을 정하고 영향 건수 확인
  - 군집: 특징 설계(런 시간 비중, 후반 감속 비율), 관성·실루엣 점수로 군집 수 선택
  - 회귀·분류: 기준선 설정, 모델 비교, 오차·혼동행렬로 결과 해석
- **과정에서 체감한 점**
  - 데이터를 어떻게 나누느냐(시즌 단위 분할)에 따라 평가 결과가 달라짐
  - 모델 점수는 단순 기준선과 비교해야 의미가 생김
